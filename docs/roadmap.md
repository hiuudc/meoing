# Roadmap

Meoing is in an early public stage. This roadmap records current maintenance priorities, not delivery dates or commitments. Priorities may change as maintainers learn from contributors and learners.

## Current priorities

1. Keep the React app, Cloudflare Worker, database migrations, and shared AI contract reproducible through CI and documented local setup.
2. Improve the language-learning workspace with accessible, keyboard-friendly practice and clear mobile behavior.
3. Strengthen the official OpenAI API integration through consent, quota, idempotency, structured-output validation, and server-side authorization tests.
4. Explore a ChatGPT app that lets learners bring the relevant Meoing workspace into a ChatGPT conversation and perform approved study actions, such as discussing answers and starting practice or lesson generation. The integration will require explicit account connection and consent, and will use the existing server-side permissions and quota controls. It is a future direction, not a currently available feature.
5. Maintain clear contributor, security, support, release, and third-party-notice documentation as the project receives feedback.

## Contribution direction

Issues and pull requests that improve reliability, accessibility, documentation, language coverage, test coverage, or safe maintenance workflows are especially useful. See [CONTRIBUTING.md](../CONTRIBUTING.md) and [SUPPORT.md](../SUPPORT.md) for participation and support paths.
