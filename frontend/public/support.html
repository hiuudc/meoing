Quick troubleshooting

The local website does not open

  1. Use Node.js 22 LTS or newer.
  2. Run npm --prefix frontend install, then npm --prefix frontend run dev.
  3. Open http://127.0.0.1:5173.

API learning is locked

Open Learn, select OpenAI API, then review and grant API consent. Confirm that the Worker health endpoint and Supabase Auth are available. API learning remains unavailable when required Worker configuration or a daily quota is exhausted.

No AI result is returned

Try the operation again with a smaller request. Do not include sign-in credentials, unrelated personal data or audio. If the issue continues, contact the maintainer with the request ID shown by the website.
