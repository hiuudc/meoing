Quick troubleshooting

The website does not open

  1. Use Node.js 22 LTS or newer.
  2. Run npm install, then npm run dev.
  3. Open http://127.0.0.1:5173.

The extension does not respond

  1. Run npm run build:extension.
  2. Load the unpacked dist-extension folder at chrome://extensions.
  3. After every build, reload the extension and refresh both Meoi and ChatGPT.

No result is returned

Confirm that you are signed in at chatgpt.com, the tab has not closed or changed conversations, and the account has not reached its quota. Meoi does not require an app, MCP, OAuth, or an API key.
