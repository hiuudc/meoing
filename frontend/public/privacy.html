Privacy

Meoing requires an account. Supabase Auth manages sign-in, while Meoing’s Cloudflare Worker authorizes all application data stored in PostgreSQL and private R2 storage.

Data we store

  • Account profile, collection membership, roles, settings, units, lessons and learning summaries are stored in PostgreSQL.
  • Uploaded files are stored in a private Cloudflare R2 bucket and are accessed only through short-lived authorized URLs.
  • Raw lesson answers, transcripts and outcomes are retained for up to one year. Audio, coaching conversations and long AI explanations are not stored.
  • The website uses IndexedDB only as a temporary outbox for progress that has not yet been acknowledged. Acknowledged batches are deleted immediately; rejected batches are shown for retry or discard. Signing out first attempts to sync and keeps any unsent batches isolated under that account so they can retry after the same user signs in again. Requesting account deletion clears that account’s device outbox.

Extension scope

The extension accepts commands only from configured Meoing origins, sends prompts through chatgpt.com, and reads only the new assistant turn created for that operation. Pending prompts and results use extension session storage. It does not read unrelated chat history, cookies, or internal network traffic.

Security and deletion

Application requests require a verified Supabase session and are checked again against collection permissions by the Worker and PostgreSQL row-level security. You can request account deletion in Meoing. Access is locked immediately, cancellation remains available for 30 days, and retained audit records are anonymized.

Audio and third-party services

Recordings stay in the browser for playback and are not uploaded by Meoing. ChatGPT, Google OAuth, Supabase, Cloudflare and the configured email provider process data needed to provide their respective services.
