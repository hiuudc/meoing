Meoing - learning workspace

Privacy

Meoing requires an account. Supabase Auth manages sign-in; the Meoing Cloudflare Worker authorizes application data stored in PostgreSQL and private R2 storage.

Data we store

  • Account profile, collection membership, roles, settings, units, lessons and learning summaries.
  • Uploaded files in private Cloudflare R2 storage, accessed through short-lived authorized URLs.
  • Progress records needed to resume and measure learning. The website uses IndexedDB only for a temporary progress outbox.

OpenAI API consent

Lesson generation, answer evaluation and coaching are optional. Before an API operation, Meoing asks for consent and sends only the learning material and answer needed for that operation to OpenAI through the Worker. Audio recordings and sign-in tokens are not sent. Requests use OpenAI's API with response storage disabled.

Meoing does not log prompts, answers, token text or lesson content in Worker logs. A short-lived validated operation result may be retained for up to 24 hours only to make a retry idempotent. You can withdraw API consent in Learn settings; API operations stop immediately.

Security and deletion

Application requests require a verified session and are checked again against collection permissions by the Worker and PostgreSQL row-level security. You can request account deletion in Meoing. Access is locked immediately, cancellation remains available for 30 days, and retained audit records are anonymized.
