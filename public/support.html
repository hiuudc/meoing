Meoi Bridge v2 · Browser-only

Khắc phục nhanh

Website không mở

  1. Dùng Node.js 22 LTS hoặc mới hơn.
  2. Chạy npm install, rồi npm run dev.
  3. Mở đúng http://127.0.0.1:5173.

Extension không phản hồi

  1. Chạy npm run build:extension.
  2. Load unpacked thư mục dist-extension tại chrome://extensions.
  3. Sau mỗi lần build, bấm Reload extension rồi refresh cả Meoi và ChatGPT.

Không nhận được kết quả

Kiểm tra rằng bạn đã đăng nhập chatgpt.com, tab chưa bị đóng hoặc chuyển cuộc chat, và tài khoản chưa chạm quota. Meoi không cần cài app, MCP hay OAuth.
