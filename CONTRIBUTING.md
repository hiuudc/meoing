# Contributing

Thank you for contributing to Meoing.

1. Open an issue before large architectural work.
2. Keep pull requests focused and include tests for changed behavior.
3. Run `npm --prefix frontend run test`, `npm --prefix frontend run build`, and applicable backend checks.
4. Do not add credentials, production identifiers, user content, generated builds, or local environment files.
5. By submitting a contribution, you agree to license it under Apache-2.0.

See [SECURITY.md](SECURITY.md) for private vulnerability reporting.
